# ドール設計図館（使い方）

『永い後日談のネクロニカ』用の非公式キャラクターシート作成・保管ツールです。

## ⚠️ ご利用にあたって

- データの取り扱いについて：本ツールに含まれるデータは、公式で配布・公開されている範囲の効果を記載しています。他マニューバの説明はルルブを参照してください。
- データ保存について：入力したデータはブラウザ（ローカルストレージ）に保存されます。

## ■ 基本の入力

- ポジション・メインクラス・サブクラスを選ぶと、武装・変異・改造のパーツ配置上限が自動計算されます。
- 「ボーナス」は武装・変異・改造のいずれか1つに+1です。寵愛による修正は手入力で加算します。
- 最大行動値は「基本行動値＋損傷していないパーツの『最大行動値+N』」で自動計算されます(内訳も表示)。
- 画面上部の固定バーには、武装・変異・改造のレベル別の使用数が出ます。表示画面(「🔒 表示」)では、最大行動値と損傷数(基本・強化・宝＝たからもの)も出ます。

## ■ スキル

- 「+ ポジション / メインクラス / サブクラス」で行を追加し、スキル名を選ぶとタイミング・コスト・射程・効果が入ります。
- タイミングが「ジャッジ・ダメージ・ラピッド」のスキルだけ、「使」チェックが出ます。
- 「時計仕掛け」「業躯」を選ぶと、Lv3の追加枠が自動で+1されます。

## ■ マニューバ(パーツ)

- 各部位の「+ パーツを選択して追加」から選びます。上限に達した種別・レベルは候補に出ません。
- 「損」を付けるとそのパーツの『最大行動値+N』が行動値から引かれます。「使」は使用済みの目印です(タイミングが「オート」「アクション」のパーツには出ません)。
- 「色」でカテゴリを選ぶと行が色分けされます。効果メモの内容から自動で判定もします。
- 「メモ」欄は、タイトルを押すと折りたためます(折りたたむと冒頭の一部が見えます)。
- 効果メモが空のパーツは「+ 効果メモを追加」で書き足せます。
- 各部位の見出しには、損傷していない残りパーツ数が出ます。損傷したパーツは灰色で、名前に取り消し線が付きます。
- 「たからもの」を損傷にすると、所持パーツから取り除かれます。

## ■ たからもの・未練・寵愛点

- 「たからもの」は枠を追加し、「パーツとして配置」で好きな部位に置けます。
- 未練の下の「発狂」欄に、発狂の名前と効果を書けます。狂気点は「0/4」の形で、−＋ボタンでも増減でき、4/4になると赤くなります。
- 寵愛点は、セッション履歴(獲得)と使い道の記録から、残りを自動集計します。

## ■ 保存・切り替え

- データはこのブラウザの中に保存されます。「💾 保存」で保存し、カードを選んで保存すると上書きになります。
- 未保存の変更は一定時間ごとに自動保存されますが、下書き枠にだけ保存されます。ページを更新したり開き直したりしたときは、直前まで編集していた内容(下書き、または最後に選んでいたキャラ)に自動で戻り、スクロール位置と折りたたみの開閉も元の状態になります。選択中のキャラクターは「💾 保存」を押すまで変わりません。「↩️ 元に戻す」で戻せるのは、行の削除・読み込み・新規作成・一括解除などの大きな操作です(文字の入力は戻せません)。
- 「🔄 切替」で保存済みキャラを一覧から切り替えられます。
- 「🆕 新規作成(白紙に戻す)」で、今の入力をすべて白紙に戻せます。保存済みのキャラは消えず、「↩️ 元に戻す」で今の入力も戻せます。
- 「🔒 表示 / ✏️ 編集」で、セッション中に見る用の表示モード(編集不可・損傷チェックのみ操作可)に切り替えます。
- 表示モードの「⚔️ 戦闘用」は、パーツ・スキル・未練・行動値だけに絞る表示です(押すと全項目を表示)。記憶のカケラは表示せず、スキルの表は、区分の列と色の凡例を省いて行を詰めます(未練の表も同じように詰め、発狂の効果文も表の幅いっぱいに出します)。そのため、1画面でたくさん見られます。
- 画面上部の固定バーは、「▲ 閉じる」で武装・変異・改造の表を畳めます。「基本」「未練」などのボタンで、その項目へ飛べます。「文字：中」を押すと、文字の大きさが 小→中→大 と切り替わります。
- 固定バーの「表：標準/ゆったり」で、スキル・マニューバの表の文字と余白を広げられます。「配色：暗/明」で、画面を白地にもできます。スキル・マニューバの見出しの下には、種別の色の意味が出ます。損傷した行は灰色(左端が赤)、使用済みの行は左端が黄色で見分けられます。
- 表示モードでも、「使用チェックを一括解除」は押せます(セッション終了時などに)。
- 削除したキャラクターは、「削除したキャラを復元」で直近5件まで戻せます。
- ブラウザの保存領域(約5MB)がいっぱいになると保存できません。使用量が8割を超えると保存時に知らせるので、その前に「全キャラをバックアップ」で書き出してください。いっぱいで保存できないときは、削除したキャラのゴミ箱を空にして保存し直します。
- 表示モードの上のバーの「🖨 印刷」で、公式のキャラクターシートに近い並びで、A4縦2枚(1枚目＝基本情報、用紙の一番下に記憶のカケラ・未練、2枚目＝最大行動値・スキル・頭腕胴脚のマニューバ(戦闘で使うものが1枚にまとまります))に印刷できます。空欄の行も残るので、印刷してから手書きで書き足せます(履歴やメモは出ません。全部を残したいときは、「画像で保存」か「JSON出力」を使います)。
- 印刷には、ページの最後に「Printed by ドール設計図館, (サイトのURL)」と小さく入ります。
- 「🏁 戦闘終了」で、使用チェックをまとめて外せます。続けて「損傷しているパーツも修復するか」を聞かれます(「↩️ 元に戻す」で戻せます)。マニューバの見出しにあります。
- 記憶のカケラは、数字・名前・詳細を分けて書けます。複数あるときは、体重や髪の色のように横に並びます(スマホでは2列)(以前に「名前：詳細」の1行で入れていたデータは、自動で名前と詳細に分かれます)。
- 記憶のカケラの詳細は、長くなっても4行ぶんで止まり、中でスクロールできます(右下の角を引くと広げられます)。また、▾ボタンで1件ずつ、または「詳細をすべて折りたたむ」でまとめて折りたためます(折りたたんでいる間は、詳細の書き出しが1行だけ薄く出ます。押すと開きます。折りたたみの状態は保存されません。印刷では、すべて開いた状態で出ます)。
- 「🖼 画像で保存」で、キャラクターシートを1枚の画像(PNG)として保存できます(共有やココフォリアの立ち絵置き場などに)。保存前に、配色(暗い背景/白い背景)と内容(すべて/戦闘用)を選べます。iPhoneでは画像が開くので、長押しで保存します。

## ■ 共有・バックアップ

- 「共有URLを作成」(出力・共有の中): 相手が開くとキャラが読み込まれます。上のバーの「閲覧用URL」: 相手の画面に表示するだけのリンクで、開いた人は編集に切り替えられません(損傷・使用のチェックだけ操作でき、保存もされません)。開いた直後は全項目が表示され、「戦闘用」で絞り込めます。
- 共有URL・閲覧用URLを作ると、キャラのデータが外部のデータベースに保存されます(URLを知っている人だけが見られます)。接続できない時は、データをURLに埋め込む方式に自動で切り替わります。
- 「🔗 発行した共有URLの控え」(出力・共有の中)に、この端末で作った共有URL・閲覧用URLが並び、「コピー」でもう一度URLを取り出せます。作ったURLは取り消せないため、URLを作る前に確認が出ます。以前作ったURLは「URLを貼って加える」で控えに入れられます。
- 「JSON出力」は、ファイルで別端末に移す方法です。上のバーの「🎲 ココフォリアコマ」で駒用のデータを、「💬 チャパレ」でチャットパレットに貼る文章をコピーできます(コマのメモ欄には名前・クラス・行動値・記憶のかけら・部位ごとのパーツ名が、ステータス欄には行動値・「○○への未練」ごとの狂気点(0〜4)と、「せぼね」など貯めて使うパーツのストック欄(0/0)が入ります。チャパレは先頭に判定コマンド、続けてポジション・クラスのスキルと頭・腕・胴・脚のマニューバが「【名前】\n《T:タイミング／C:コスト／R:射程》\n効果」の形で並び、攻撃マニューバには行頭に 1na が付きます。ココフォリアのルームのシステムは「ネクロニカ」にしてください)。
- 「全キャラをバックアップ」で、保存済みの全キャラを1つのファイルに書き出せます。ブラウザのデータが消えた時や機種変更の保険として、時々取っておくのがおすすめです。最後に取ってからの日数が、キャラクター管理に表示されます(14日以上たつと色が変わります)。
- データ未登録のスキル・パーツに自分で書いた効果は、このブラウザに覚えられます。次からは、同じスキル・パーツを選ぶと自動で入ります(「全キャラをバックアップ」にも一緒に入ります)。
- 「保管所テキストから読み込む」(キャラクター管理の「削除したキャラを復元」の隣)で、キャラクター保管所の「テキスト出力」を貼り付けると、キャラ名・身長・体重・髪/瞳/肌の色・クラス・スキル・マニューバ(パーツ。効果メモや名前に「たからもの」とあるものは、分類が「たからもの」になります)・記憶のカケラ・未練(発狂時の名前・効果を含む)・セッション履歴(獲得寵愛)が反映されます(テキストに入っている項目だけが上書きされ、「↩️ 元に戻す」で戻せます)。強化値は、ボーナス(+1する列)と寵愛による修正を反映します。メインクラス・サブクラス・合計と最大行動値は自動計算のため、テキストと違う場合は読み込み結果に表示されます。読み込めなかった行と、シートに欄が無い成長履歴の文章は、ページ下部の「メモ」欄に追記されます(今のメモは消えません)。
