# README（使い方）

『永い後日談のネクロニカ』のキャラクターシート補助ツールです。

## ⚠️ ご利用にあたって

- データの取り扱いについて：本ツールに含まれるデータは、公式で配布・公開されている範囲の効果を記載しています。他マニューバの説明はルルブを参照してください。
- データ保存について：入力したデータはブラウザ（ローカルストレージ）に保存されます。

## ■ 基本の入力

- ポジション・メインクラス・サブクラスを選ぶと、武装・変異・改造のパーツ配置上限が自動計算されます。
- 「ボーナス」は武装・変異・改造のいずれか1つに+1です。寵愛による修正は手入力で加算します。
- 最大行動値は「基本行動値＋損傷していないパーツの『最大行動値+N』」で自動計算されます(内訳も表示)。

## ■ スキル

- 「+ ポジション / メインクラス / サブクラス」で行を追加し、スキル名を選ぶとタイミング・コスト・射程・効果が入ります。
- タイミングが「ジャッジ・ダメージ・ラピッド」のスキルだけ、「使」チェックが出ます。
- 「時計仕掛け」「業躯」を選ぶと、Lv3の追加枠が自動で+1されます。

## ■ マニューバ(パーツ)

- 各部位の「+ パーツを選択して追加」から選びます。上限に達した種別・レベルは候補に出ません。
- 「損」を付けるとそのパーツの『最大行動値+N』が行動値から引かれます。「使」は使用済みの目印です(タイミングが「オート」「アクション」のパーツには出ません)。
- 「色」でカテゴリを選ぶと行が色分けされます。効果メモの内容から自動で判定もします。
- 効果メモが空のパーツは「+ 効果メモを追加」で書き足せます。
- 「たからもの」を損傷にすると、所持パーツから取り除かれます。

## ■ たからもの・未練・寵愛点

- 「たからもの」は枠を追加し、「パーツとして配置」で好きな部位に置けます。
- 寵愛点は、セッション履歴(獲得)と使い道の記録から、残りを自動集計します。

## ■ 保存・切り替え

- データはこのブラウザの中に保存されます。「💾 保存」で保存し、カードを選んで保存すると上書きになります。
- 未保存の変更は一定時間ごとに自動保存されます。「↩️ 元に戻す」で直前の削除などを戻せます。
- 「🔄 切替」で保存済みキャラを一覧から切り替えられます。
- 「🔒 表示 / ✏️ 編集」で、セッション中に見る用の表示モード(編集不可・損傷チェックのみ操作可)に切り替えます。

## ■ 共有・バックアップ

- 「共有URLを作成」: 相手が開くとキャラが読み込まれます。「閲覧用URLを作成」: 相手の画面に編集不可で表示するだけのリンクです。
- 共有URL・閲覧用URLを作ると、キャラのデータが外部のデータベースに保存されます(URLを知っている人だけが見られます)。接続できない時は、データをURLに埋め込む方式に自動で切り替わります。
- 「共有コード」「JSON出力」は、文字列やファイルで別端末に移す方法です。「ココフォリア出力」で駒用のデータをコピーできます。
- 「全キャラをバックアップ」で、保存済みの全キャラを1つのファイルに書き出せます。ブラウザのデータが消えた時や機種変更の保険として、時々取っておくのがおすすめです。
